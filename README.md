# FLS_11-7_E1

## Beschreibung

Dieses Projekt wurde im Rahmen meiner Schularbeit erstellt. Es handelt sich um
ein einfaches Java-Programm, das den Text `Hello, World!` in der Konsole ausgibt.

## Voraussetzungen

Für die Ausführung wird eine installierte Java-Version benötigt.

## Verwendung

Das Programm kann mit folgenden Befehlen gestartet werden:

```bash
javac Hello_World.java
java Hello_World
```

Als Ausgabe erscheint:

```text
Hello, World!
```

## Dateistruktur

```text
FLS_11-7_E1/
├── Hello_World.java   # Java-Hauptprogramm
├── README.md          # Projektbeschreibung
└── Hello_World.class  # kompilierte Datei (nach javac)
```

## Lernziel

Mit diesem Beispiel übe ich die Grundlagen von Java: Klassen, die
`main`-Methode und die Ausgabe mit `System.out.println`.
